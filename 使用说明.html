MAHO REFERENCE COLLECTOR / 3.1.0

把参考留下来，
把时间留给画画。

一个属于你的素材收集插件。中文界面，本机保存，没有账号、订阅或云端上传。

安装收图下载保存与迁移适用范围

01 / 安装一次

  1. 完整解压安装包，保留在固定文件夹。
  2. 打开 edge://extensions 或 chrome://extensions，启用开发者模式。
  3. 选择“加载已解压的扩展”，选中直接包含 manifest.json 的文件夹。
  4. 在浏览器工具栏固定 MAHO 拾图。快捷键为 Alt + Shift + P，可在浏览器扩展快捷键设置中修改。

以后更新：替换同一文件夹里的插件文件，再在扩展管理页点击“重新加载”。先导出重要记录。不要删除这个安装文件夹。

02 / 三种收图方式

整页提取
打开素材网页 → 点插件图标 → 提取当前页。支持常见图片、srcset 大图候选、懒加载属性；背景图需在整理页勾选后重新提取。也会扫描可访问的同源内嵌页面和开放的 Shadow DOM。
随手收集
在插件弹窗点“随手收集”。鼠标移到图片上点“＋收集”，或 Alt + 点击图片；也可把图片拖入右下角浮层。结果放入收集篮，不会立即大量下载。结束收集、Esc 或刷新页面会关闭此模式。
多个页面一起整理
点“选择多个页面”，允许读取当前窗口标签列表，勾选最多 12 个页面，再点提取。只会请求你所选网站的权限；未能读取的页面会提示。多页批次要补充内容，请从弹窗重新选页提取。

图片右键还有“收进 MAHO 素材篮”。“打开收集篮”会创建一份整理批次，保留来源；清空篮子不会影响已经生成的批次。

03 / 挑出值得练的

左侧可组合宽高、长边、横竖比例、格式、域名、文字关键词和分类条件。未知尺寸可暂时保留，之后点击“读取未知图片尺寸”。格式根据网址推测，ZIP 则会读取实际文件类型。

人物、头像表情、动物、线稿都能手动标记。点击大图可收藏、写练习笔记，滚轮细调缩放；← → 换图，空格选中，Esc 返回。默认适屏，点击缩放百分比可复位。

“选中清晰参考”只依据尺寸及疑似图标名称；“按说明辅助分类”只依据图片描述中的词语。它们不进行 AI 画面识别，也不判断临摹难度。

全选筛选结果只增加选择；下载会包含筛选之外仍被选中的图片，数量会显示在工具栏。整理操作支持撤销。

04 / 保存到自己的素材夹

点击整理页顶部的“保存位置”，再点“选择文件夹…”。在系统窗口中选择自己的素材文件夹并允许写入，例如 D:\绘画素材。选择后会在本机记住，并应用到图片、ZIP、CSV、JSON 和整批记录。

我指定的文件夹
选择一次，批量保存。图片按“所选文件夹 / 本次子文件夹 / 分类或网站 / 文件名”归档；ZIP 直接保存在所选文件夹中，来源清单保存在本次子文件夹中。同名文件自动添加编号，不覆盖已有素材。下次打开浏览器可能要求再次授权，点击“允许写入此文件夹”即可。取消选择文件夹会保留原位置。
每次弹窗选择位置
每个文件弹出系统保存窗口，可选择任意允许的文件夹或修改文件名。为避免多个窗口同时出现，图片按顺序逐个保存；取消或失败后停止后续任务。此方式不自动创建分类子文件夹。图片很多时，先打包 ZIP，只需为整个 ZIP 选择一次位置。
浏览器默认下载目录
沿用浏览器设置里的下载位置，归档到其中的“MAHO 拾图”文件夹。批量图片三张并行，停止按钮只阻止后续任务，已开始的任务会继续。
格式与访问权限
直接写入指定文件夹和 ZIP 会读取图片内容，需要允许访问图片所在网站。支持 JPG、PNG、GIF、WebP、AVIF、BMP，保持原始字节，单图最多 25 MB。SVG、更大的图片或某些限制读取的网站，可以切换为“每次弹窗选择位置”，再点“保存所选图片”，由浏览器处理下载。
打包 ZIP ＋ 来源
把成功取得的图片和“来源清单.json”一起打包，最多 200 张 / 100 MB。部分失败时，成功图片仍会保存，失败原因写入清单；“停止并保存已有图片”保留已取得的文件。指定文件夹方式显示“已保存”表示写入已完成；浏览器方式以下载列表的最终状态为准。

“本次子文件夹”只填这一批的名字，例如“动物轮廓练习”，不要填写完整磁盘路径。设置区会显示预计的归档结构。保存期间保持整理页开启；当前任务结束后再更换位置。

05 / 本机记录与旧版迁移

选图、分类、笔记和收藏自动保存在本机，最近 20 个批次可从历史继续整理。收集篮最多 500 张；同一完整图片网址去重，不是视觉相似去重。

旧“慢慢拾图”的“备份整批记录”或来源 JSON 可导入。新插件使用独立数据空间，无法自动读取旧插件。来源清单保存网址和记录，不含图片字节；需要离线图片时请下载图片或 ZIP。

卸载插件、删除浏览器资料或换浏览器会失去本机记录。将重要批次导出保留；私人素材不会自动上传到你的作品集网站。

06 / 使用范围

本版面向桌面 Chrome / Edge，使用 Manifest V3。只提取网页已经声明、浏览器有权访问的图片；不绕过登录或付费限制。列表页可能只有缩略图，想要更大的图片可进入作品详情页重新提取。

浏览器设置页、扩展商店、跨域内嵌页面、关闭的 Shadow DOM、canvas 和临时 blob 图片不保证可读取。无限滚动网页请先滚动加载，再重新提取；插件不会自动翻页。

为控制页面开销，单次最多扫描 20,000 个元素、嵌套 4 层，每批最多 1,500 个候选地址，并有传递体积上限。超过时提示分批处理。

仅通过浏览器向图片所属网站请求图片，没有统计或第三方服务。多页扫描、指定文件夹保存和 ZIP 会请求额外站点权限，可在浏览器扩展管理页撤回；普通当前页提取使用临时 activeTab 授权。

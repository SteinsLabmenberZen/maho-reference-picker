## 安装后建议先试

1. 打开一个普通图片页面，提取并筛选 3 张图片。
2. 选择一个专用素材文件夹，保存 3 张图片和一个 ZIP，核对文件实际位置、分类目录和图片内容。
3. 再保存同一批，确认原文件仍在，新文件带编号；刷新整理页，核对位置记忆和重新授权。
4. 切换“每次弹窗选择位置”，尝试保存和取消各一次；再测试浏览器默认模式。
5. 开启随手收集，测试悬停按钮、Alt + 点击与拖入浮层，再打开收集篮。
6. 刷新整理页，确认分类、收藏和笔记仍在。
7. 如需旧数据，导入一份旧“慢慢拾图”的 JSON，并核对记录数量。

某网站失败时请提供网页地址、失败提示和使用方式；不要发送账号密码或 Cookie。

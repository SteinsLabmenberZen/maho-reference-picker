# MAHO 拾图 3.1.0

适配桌面 Chrome / Edge 的个人绘画参考收集扩展，Manifest V3。
参考 Image Picka，在原“慢慢拾图”基础上改造。不是 Image Picka 官方版本。

## 使用

**[下载 3.1.0 安装包](downloads/MAHO-Reference-Picker-3.1.0-Install.zip?raw=true)**

1. 下载并完整解压到固定文件夹。
2. 打开 `chrome://extensions` 或 `edge://extensions`，启用开发者模式。
3. 点击“加载已解压的扩展”，选择直接包含 `manifest.json` 的文件夹。
4. 打开素材网页，点击 MAHO 拾图图标开始收集。

无需 Node.js 或编译。先完整解压，按 START-HERE.txt 加载已解压的扩展。
完整中文教程见 使用说明.html，可从插件弹窗打开。

- 当前页、多标签页图片提取；开放 Shadow DOM、同源 iframe、大图候选和可选背景图。
- 按需开启悬停 / Alt + 点击 / 拖入收集篮；图片右键快收。
- 尺寸、比例、格式、关键词筛选；人物 / 动物 / 线稿分类、收藏、笔记。
- 自选并记住素材文件夹、逐个文件另存为、浏览器默认下载三种保存方式。
- 图片、可取消 ZIP 打包、CSV / JSON 来源清单、整批记录统一使用保存位置；按分类或来源归档，同名自动编号。
- 滚轮微调预览缩放，本机历史批次，导入旧版 JSON 记录。

单次 12 个页面、每批 1500 个候选、收集篮 500 张。
ZIP 每次 200 张 / 100 MB。直接保存到指定文件夹及 ZIP 单图最多 25 MB，支持 JPG / PNG / GIF / WebP / AVIF / BMP。
浏览器下载方式不设上述体积和格式限制；SVG 或大图可切换为“每次弹窗选择位置”后保存所选图片。
图像内容识别、全站爬取、云端同步不在本版范围。

## 设置保存位置

整理页顶部点击“保存位置” → “选择文件夹…” → 选中自己的素材文件夹并允许写入。
图片将保存在“所选文件夹 / 本次子文件夹 / 分类或来源网站”中；ZIP 保存在所选文件夹根目录。
保存模式和文件夹句柄通过独立 IndexedDB 记在本机，不会上传，也不包含在导出的来源清单中。
下次打开可能需要点击“允许写入此文件夹”。浏览器不支持文件夹选择时，改用“每次弹窗选择位置”。
逐个弹窗模式每次只处理一个文件，取消或失败后停止后续任务，避免连续弹出保存窗口。

从 3.0 更新：先保留重要记录的备份，关闭旧整理页，把新包内文件覆盖到原安装目录，
在扩展管理页点击“重新加载”，再重新打开插件。不卸载插件，不改变原安装目录。

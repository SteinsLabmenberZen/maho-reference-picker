MAHO 拾图 3.1.0 · Chrome / Edge 个人使用版

先把压缩包全部解压到固定位置，不需要 Node.js，不用运行命令。

安装：
1. Edge 地址栏输入 edge://extensions
   Chrome 地址栏输入 chrome://extensions
2. 打开“开发人员模式 / 开发者模式”。
3. 点击“加载解压缩的扩展 / 加载已解压的扩展程序”。
4. 选择本文件所在的已解压文件夹。
   这个文件夹内应直接看到 manifest.json，不要选择它的外层文件夹。
5. 在浏览器扩展菜单中，把“MAHO 拾图”固定到工具栏。

如果提示“清单文件丢失或不可读取”：
先取消加载，在资源管理器打开刚才选择的文件夹。
如果里面还有一层同名文件夹，请进入这一层，直到直接看到
manifest.json、background.js、popup.html 等文件，再选择该文件夹加载。
不要直接从压缩包窗口加载，也不要选择单独的 manifest.json 文件。
本次重新整理的安装包已经去掉外层嵌套目录。

已经安装 3.0 的更新方式：
1. 先导出重要批次记录，关闭旧的素材整理页。
2. 将新压缩包内的文件，覆盖到原先直接包含 manifest.json 的安装目录。
3. 扩展管理页找到 MAHO 拾图，点击“重新加载”，再打开插件。
沿用原安装目录更新，不要先卸载插件，以保留本机整理记录。

设置图片保存位置：
整理页顶部点“保存位置” → “选择文件夹…” → 选一个自己的素材文件夹。
确认浏览器的写入授权后，保存方式会自动改为“我指定的文件夹”。
图片、ZIP、来源清单和整批记录都会使用这个位置，下次打开也会记住。
如果显示“需要允许写入”，点“允许写入此文件夹”。
“本次子文件夹”填写这批素材的名称，比如“动物轮廓练习”，不要填写完整磁盘路径。
也可以在“保存方式”里选“每次弹窗选择位置”或“浏览器默认下载目录”。

第一次使用：
打开一张普通素材网页，点 MAHO 图标 → 提取当前页。
选择图片 → 保存所选图片，或“打包 ZIP ＋ 来源”。
也可开启“随手收集”，悬停点“＋收集”、Alt + 点击、把图片拖入浮层。
图片右键也有“收进 MAHO 素材篮”。

从旧“慢慢拾图”迁移：
先在旧插件“备份整批记录”，再在新插件“导入来源清单”。
新插件不会自动读到旧插件的数据。旧插件可以暂时保留，验证后再决定是否移除。
JSON 来源清单只含记录；ZIP 才包含本次成功下载的图片。

详细说明：
用浏览器打开“使用说明.html”，或从插件弹窗点击“使用说明”。
